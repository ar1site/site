# Filmagem com drone integrada ao site

Rota oficial: https://ar1films.com/filmagem-com-drone. Repositório de produção: `ar1site/site`; projeto Vercel: `ar1films`, equipe `ar-1-films`. A branch `main` publica em produção pela integração GitHub/Vercel.

A página apresenta a AR1 como produtora audiovisual completa. Não divulga quantidade nem modelos de drones: os recursos são descritos por aplicação, para manter o conteúdo útil mesmo quando o equipamento mudar.

## Manutenção

- Texto editorial compartilhado entre React e a geração estática: `src/pages/drone-content.html`.
- Componente, mensuração do CTA e destaque usado na home, Soluções e Fotografia e vídeo: `src/pages/DroneContent.tsx`.
- Estilos isolados: `src/pages/drone.css`.
- Cinco imagens ilustrativas: `public/media/drones/`. Não são projetos, equipe ou clientes reais da AR1. Ao inserir material próprio, ajustar também as legendas e os textos alternativos.
- Cabeçalho, rodapé, WhatsApp e formulário são os existentes no site. O formulário seleciona o interesse de filmagem com drone e usa o fluxo `/api/proposta` já existente.
- Metadados, conteúdo HTML inicial e dados estruturados Service/BreadcrumbList: `scripts/prerender.mjs`. O sitemap inclui a rota oficial.

## Validação e publicação

Executar `npm ci --ignore-scripts`, `npm run build`, `npm run test:site`, `npx oxlint src scripts tests` e `npm audit`. Conferir a prévia em desktop e celular antes de integrar a branch à `main`.

Os testes verificam conteúdo disponível sem JavaScript, canonical, dados estruturados, sitemap, imagens, identificadores e âncoras. Não enviar propostas fictícias ao formulário de produção durante os testes.
